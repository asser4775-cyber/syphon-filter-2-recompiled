Syphon Filter 2 Recompiled v0.1.0-alpha

This is an experimental static recompilation of Syphon Filter 2 Disc 1,
USA release SCUS-94451. It does not include the game, a Sony BIOS, saves,
or extracted assets.

First launch:
1. Run SyphonFilter2Recompiled.exe.
2. Select your legally obtained Syphon Filter 2 Disc 1 image when prompted.
   Pick the .cue file when your dump has a .cue and one or more .bin files.
3. The verified disc path is remembered in disc.cfg.

The MIT-licensed OpenBIOS from PCSX-Redux is bundled; a Sony BIOS is not
required. Memory cards are created under saves/.

Important alpha limitations:
- Disc 1 is the current validation target; Disc 2 is not yet qualified.
- Gameplay keeps the retail 20 Hz world update. Experimental 60 Hz
  interpolation was rejected and is not present.
- The resident executable is statically recompiled. Uncovered streamed
  overlays use the compatibility interpreter, so native coverage is partial.
- Native 16:9, PGXP, and direct mouse camera have passed Mission 1 testing;
  the complete campaign still needs public playthrough coverage.

See README.md for controls, known limits, reporting instructions, and license.
